# Pelican Cyclist · SVG · Improvement archive

**Evidence level:** Prompt evolution — Basic → Advanced specification refinement

## Starting point

A one-line request: create code for an SVG of a pelican riding a bicycle as nicely as possible.

## What changed

1. **Standalone accessible vector delivery** — Responsive pure SVG with title/description, gradients, clipping and native animation replaces the open-ended output format; bitmap and external assets are excluded.

2. **Anatomy and bicycle structure are detailed** — Feathers, beak, throat pouch, eyes, webbed feet, diamond frame, spokes, fork, chain and pedals must form a credible riding pose.

3. **Motion and accessibility become constraints** — Consistent wheel/crank motion, feet on pedals, body bob, blinking, moving scenery and a complete prefers-reduced-motion pose are required.
