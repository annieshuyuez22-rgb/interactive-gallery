Pelican Cyclist · SVG · 鹈鹕骑自行车

Final presentation

Prompt evolution

Starting point

A one-line request: create code for an SVG of a pelican riding a bicycle as nicely as possible.

Evidence standard: Basic → Advanced specification refinement

Refinement sequence

What changed

3 documented implementation or specification improvements.

  1. 01

    Standalone accessible vector delivery

    Responsive pure SVG with title/description, gradients, clipping and native animation replaces the open-ended output format; bitmap and external assets are excluded.

  2. 02

    Anatomy and bicycle structure are detailed

    Feathers, beak, throat pouch, eyes, webbed feet, diamond frame, spokes, fork, chain and pedals must form a credible riding pose.

  3. 03

    Motion and accessibility become constraints

    Consistent wheel/crank motion, feet on pedals, body bob, blinking, moving scenery and a complete prefers-reduced-motion pose are required.

Versions & evidence

Evidence boundary

This entry documents specification refinement from Basic to Advanced. It does not prove that every requirement was implemented or verified, and it is not presented as a complete code iteration log.
