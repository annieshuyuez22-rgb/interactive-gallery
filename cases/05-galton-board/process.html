Galton Board · 粒子碰撞、高尔顿板、方块碰撞

Final presentation

Prompt evolution

Starting point

A single-file Galton board with about 12 peg rows, collision-driven distribution, colored balls, bins, a histogram and pause/speed controls.

Evidence standard: Basic → Advanced specification refinement

Refinement sequence

What changed

3 documented implementation or specification improvements.

  1. 01

    Collision and counting become stricter

    Twelve rows map to thirteen bins, with substeps, non-overlapping settled stacks and counting only after a ball settles.

  2. 02

    Trajectories and data become easier to read

    Peg highlights, contact shadows, hit flashes, recent-ball trails, exact bin counts and a shared scale are added.

  3. 03

    Interaction and performance become measurable

    Reset, Single Drop, 1–20 balls/second, active/settled/total counts and measured FPS are required, with sleeping settled balls retained.

Versions & evidence

Evidence boundary

This entry documents specification refinement from Basic to Advanced. It does not prove that every requirement was implemented or verified, and it is not presented as a complete code iteration log.
