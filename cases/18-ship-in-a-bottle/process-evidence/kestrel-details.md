# S.V. KESTREL — 瓶中船 · Voxel Hydrodynamics — 细节轮次记录

参考原帖：vib3coded《ship in a bottle》双槽对比视频（18s，瓶中帆船+海洋体素+桌面场景）。
目标：逐元素复刻原帖构图/配色（灯塔岛+帆船+棕榈岛+软木塞红蜡+铭牌架+桌面），每轮 +50 可视细节。
目标文件：`index.html`（单文件 Three.js，ES module + importmap `./vendor/three.module.js`，必须走 http）。
录制时间线（`?record=1`，16.2s）：noon → 2.6s 舷炮齐射 → 5.2s sunset → 8.2s 流氓浪 → 11.4s bio → 14.6s noon；相机 CatmullRom 绕瓶一周。

## 第 1 轮（R1）— 细节 R1-01 … R1-50

技术约定（本轮确立，后续轮次沿用）：
- 全部新随机走独立确定性流 `mulberry32(20261014)`（`rng1`），原 `Math.random()` 序列零扰动，原布局 bit-identical。
- 静态小体素优先合批：`bakeBatch()` 一个 `InstancedMesh` + `instanceColor` 一次 draw call（船/瓶内/灯塔/桌面各一批）；重复动态体（浪沫/鱼群/岸线泡沫/灯光舷窗）亦用 InstancedMesh。
- 所有新动画收进唯一入口 `updateR1(dt, t)`（index.html:742），挂入主循环 `tick()`（index.html:1990）；全部状态为 `t` 的周期/收敛函数，循环重放自动复位。
- 灯光联动约定：`R1.light` 平滑跟随天气——bio/storm 全亮、sunset 45%、noon 熄灭；`R1.sky` 驱动星空/流星/月亮（bio 最强）。
- 备份：`index.html.bak-r1`（首轮前快照，勿覆盖）。
