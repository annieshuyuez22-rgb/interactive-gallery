Refinement sequence

What changed

6 documented implementation or specification improvements.

  1. 01

    R0 → R1: 50 documented details

    The first refinement adds 50 enumerated visual and interaction details. Independent deterministic random streams preserve the original layout, while instancing and a centralized update function control the added animation cost.

  2. 02

    R1 → R2: 50 more documented details

    A second independent random stream and bake pass add weather-reactive jellyfish, rain rings, lightning reflections, cloud shadows and other scene behavior without resetting the earlier composition.

  3. 03

    R4: glass, rigging and camera behavior

    A later project line refines hollow glass, curve highlights, physical rigging and lighthouse beams. Manual camera selection now stops automatic rotation. Only the five actually documented R4 motion details are claimed.

  4. 04

    Brighter studio and director timeline

    The R4 presentation introduces a brighter studio, layered blue water and a wall-clock camera timeline so software rendering does not slow the intended transitions.

  5. 05

    The Bottled Sea: source-level visual refinement

    The preserved before/after sources show deeper water, richer storm mixing, wakes and spray, curved sails, physical rigging, ship lights, adjusted glass reflections and rebalanced day/night fill and rim lighting.

  6. 06

    Non-destructive recording and deterministic fallback

    Output and frame paths can be redirected instead of overwriting earlier takes. A wider final hero shot and explicit fallback state improve repeatable recording.
