Basic prompt
做一个可交互的 voxel 风 ship-in-a-bottle 3D 网页场景（单个自包含 HTML + Three.js）：玻璃瓶横放在木桌支架上（KESTREL·1742 铭牌、软木塞+火漆印），瓶内有体素海洋（波浪实时起伏）、三桅帆船（随浪浮沉/横摇）、红白条纹灯塔（旋转光束+发光灯室）、云、鲸鱼、棕榈小岛、海底珊瑚；右侧控制面板：天气预设（Tropical Noon / Golden Sunset / Bioluminescent / Maelstrom Storm）、交互物理（Rogue Wave / Fire Broadside / Shake Bottle / Glass Shell 开关）、流体参数滑杆（浪幅/风速/瓶体俯仰）、相机预设（全瓶/帆船特写/海底珊瑚/灯塔）。
