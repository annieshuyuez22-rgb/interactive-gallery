# 白尾鹿单体建模 Prompt（hyper3d Rodin）

## 提交参数
- `--mesh-mode Quad --quality 50000 --format glb`（四边形，面数开最大，1 credit）
- 输入图：`ref/view_34.png`（3/4 侧后视角）、`ref/view_side.png`（正侧视角）

## 关键声明（防止多体粘连）
随附的参考图展示的是**同一个物体——一只鹿——的不同视角**，不是多个物体。请只生成**一只单独的鹿**模型，单根节点、单个网格，严禁把不同视角理解为多只鹿或生成多个粘连的模型。

## 资产描述
一只奔跑姿态的白尾鹿（white-tailed deer），风格化为干净光滑的写实卡通渲染质感：

- **体型**：修长优雅的鹿，长颈、窄胸、长腿，身体呈流线型
- **配色（矿物暖棕 + 奶油白分区）**：
  - 背部与体侧：暖赭棕色（tan/ochre brown），光滑短毛
  - 腹部、颈下、腿内侧：奶油白色
  - 肩部与后腿上部有白色斑区块面
  - 尾巴：白色短尾上翘（白尾鹿标志性旗状尾）
  - 小腿下部至蹄：深棕黑色，蹄为黑色
  - 鼻镜黑色，眼周有浅色环
- **鹿角**：雄性分枝状鹿角，暖棕褐色，多叉（每侧 4-5 个叉尖），从头顶向后上方伸展
- **姿态**：动态奔跑/腾跃姿态，前腿收起弯曲，后腿蹬伸，身体伸展
- **材质**：哑光短毛质感，明暗分区清晰，不要高反光塑料感

## 验收
- 单个物体、单网格；姿态、配色分区、鹿角形态与参考图一致
- 出现多体粘连/多只鹿即判定失败，需重新提交
Advanced prompt
以用户提供的deer_scene.blend、deer.glb、参考视频与1021-小鹿-v1工程为基础，保留模型、材质和50mm镜头，精修Kimi侧16帧步态：明确伸展、承重、蹬伸和回收，错开左右腿相位，协调重心、脊柱、颈头与尾部，加入轻微跟镜和0.18帧快门运动模糊。使用Blender原生EEVEE渲染65帧，双侧以相同源时间窗口插帧，完整动作、细节和结尾统一2×加速，输出15秒1080p60双栏视频kimi-v2.mp4。
