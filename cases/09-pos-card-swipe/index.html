Prompt archive

From brief to build

Basic prompt
Generate the code of a continuous SVG animation of a minimal isometric card swiping machine and a sleek bank card, where the card smoothly slides down and across the side reader slot with a glowing smart chip, triggering a white paper receipt with dashed cut lines and tiny text blocks to unroll from the top printer slot before a bright success checkmark stamp pops onto the paper. The design should feature a clean flat UI style using slate gray, mint green, and subtle white highlights, with smooth CSS easing for all moving elements
Advanced prompt
Generate the complete code for a standalone, continuously looping SVG animation of a minimal isometric card-swiping machine and a sleek bank card. Use SVG vector geometry and embedded CSS animations with smooth easing; no raster images or external assets. Preserve a clean flat UI style using slate gray, mint green, and subtle white highlights.

Draw a coherent 30-degree isometric payment terminal with distinct top, front, and side faces, rounded corners, a recessed dark screen, a small keypad, a narrow side reader slot, and a printer opening on top. Use slate #334155, dark slate #17212F, mint #7CFFB2, and warm white #F8FAFC. Separate surfaces through value and crisp edges rather than heavy shadows. Place the terminal over a restrained elliptical ground shadow.

The card starts above and beside the side reader, displaying a mint edge, a glowing smart chip, four tiny masked-number groups, and a simple embossed stripe. It slides smoothly downward into alignment and then across the reader slot. Use clipping and layer order so the inserted section passes behind the reader lip instead of visibly floating over the housing. The chip glow intensifies only during the swipe.

After the swipe completes, illuminate the screen with a mint confirmation pulse. A white receipt unrolls upward from the printer opening, revealing dashed cut lines and tiny aligned text blocks progressively; keep the paper behind the slot edge until it emerges. A bright mint success checkmark stamp then pops onto the paper with one short squash-and-settle motion. Hold the completed transaction briefly, remove the card, retract the receipt, and return to the initial state without a visible jump.

Use a clearly staged eight-second loop with no overlapping transaction phases. Maintain consistent isometric alignment throughout, ensure the checkmark remains readable at small size, and include an accessible title plus a reduced-motion static success state. Return only the SVG code.
